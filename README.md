# Super Downloader

**A free, open-source download manager for everyone.** For Android and iPhone.

## What it does

Super Downloader grabs any file from any link, fast. It splits each download into several pieces and pulls them at the same time, so big files finish much quicker than in a normal browser.

### Features
- **Multi-connection downloads**: up to 16 connections per file, with smart re-splitting so no connection sits idle.
- **Any link, any file type**: paste a link, share one from another app, or let it spot links you copy. It saves any file type and detects the real type automatically.
- **No size limits**: handles files over 4 GB.
- **Background downloads**: keeps going when you leave the app, with live notifications showing progress, speed and ETA, plus pause, resume and cancel.
- **Pause and resume**: survives network drops, app restarts and reboots.
- **Built-in browser**: for sites that make you visit the page first. It catches the download and keeps your session so protected links work.
- **Detailed download page**: file info, source and web page links, priority, live speeds (current, average, peak, per connection), speed graph, and a piece-by-piece progress map.
- **Organised storage**: its own Super Downloader folder, sorted into Video, Music, Documents, Archives, Programs, Images and Other.
- **Full control**: traffic modes (Low, Medium, High, Unlimited), speed limits, connection limits, scheduler, priorities, Wi-Fi-only, proxy and custom user agent.
- **Extras**: batch downloads, a link grabber for pages, QR code links, checksum checks (MD5 and SHA-256), play while downloading, auto-unzip, a private Face ID or fingerprint folder, a home-screen widget, and download stats.
- **Premium red and black design**: with dark and light modes, and it runs smoothly on low-end phones.

## Download
Get the latest APK (Android) and IPA (iPhone) from the **Releases** page.

- **Android**: open the APK and allow installing from this source.
- **iPhone**: the IPA is unsigned, so install it with AltStore, Sideloadly or TrollStore.

## Good to know
- Content protected by DRM or streaming-only video can't be downloaded.
- Google blocks sign-in inside in-app browsers, so Google sign-in opens in Safari or Chrome.
- On iPhone, iOS decides how much bandwidth background downloads get.
